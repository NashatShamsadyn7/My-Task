# طالب الجامعة

تطبيق Android عربي لإدارة الحياة الجامعية والمهام الشخصية والشقة والمال في مكان واحد.

## حالة المشروع

تم إنجاز Phase 1 foundation: بنية modular، واجهة RTL، نظام ألوان، تنقّل رئيسي، نماذج أساسية، وخدمة محلية قابلة للتوسعة. تتطلب متابعة بناء Android تثبيت Flutter SDK ثم تشغيل `flutter create .` لإنشاء مجلدات المنصات و`flutter pub get`.

## مبادئ مالية مهمة

- كل مبلغ مالي يمثل `int` بالدينار العراقي، لا `double`.
- الرصيد ناتج من دفتر معاملات، وليس قيمة صامتة قابلة للتعديل.
- شراء الشقة المدفوع من مال المستخدم ينشئ مصروفاً شخصياً واحداً والتزام استرداد صافياً فقط.

## البدء بعد تثبيت Flutter

```powershell
flutter create .
flutter pub get
flutter test
flutter analyze
flutter run
```

لا تُضاف إعدادات Firebase أو مفاتيحها إلى Git. راجع `docs/architecture.md` قبل Phase 2.
